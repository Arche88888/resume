หัวหน้าฝ่ายพัฒนาธุรกิจและการขาย
บริษัท ไปรษณีย์ไทยดิสทริบิวชั่น จำกัด (ปณด) — กลุ่มไปรษณีย์ไทย
2026 – ปัจจุบัน | โลจิสติกส์ กระจายสินค้า และการค้าระหว่างประเทศ | กรุงเทพฯ
  • นำฝ่ายพัฒนาธุรกิจและการขาย — กลยุทธ์รายได้ของฝ่าย ไปป์ไลน์ โครงสร้างราคา และพันธมิตร ภายใต้โจทย์กระจายฐานรายได้ออกจากการพึ่งพาบริษัทแม่และงานภาครัฐ
  • นำโครงการเชื่อมต่อแพลตฟอร์มการค้าดิจิทัลระดับประเทศ — วางตำแหน่งบริษัทเป็นชั้นเครือข่ายภาคพื้น (First-Mile / Last-Mile / LTL) ของ gateway การค้าระหว่างประเทศ เปลี่ยนรถเที่ยวเปล่าขากลับให้เป็นรายได้ · เขียนวาระเสนอคณะกรรมการ เงื่อนไขเชิงพาณิชย์ และกรอบความเสี่ยงเอง แล้วผลักผ่านอนุกรรมการถึงคณะกรรมการบริษัท
  • สร้าง Sales OS ของฝ่ายตั้งแต่ต้นจนจบ — รับลีด คัดกรอง ตั้งราคา ทำข้อเสนอ และรอบทบทวนรายสัปดาห์ พร้อมรายงานผล 60 วันแรกต่อผู้บริหาร
  • ออกแบบโครงสร้างราคาของฝ่าย — Fuel Rate Card, Multidrop, พัสดุหนัก, Cold Chain, Multimodal พร้อมเครื่องมือคำนวณที่ทีมใช้เสนอราคาได้เอง และนำบริการใหม่เหล่านี้ออกสู่ตลาดตั้งแต่วิเคราะห์คู่แข่งถึงข้อเสนอเชิงพาณิชย์
  • รับผิดชอบกรอบประเมิน KPI ของฝ่ายพัฒนาธุรกิจและฝ่ายการตลาด งบประมาณปี 2570 และประมาณการรายได้–ต้นทุนการลงทุน
  • Same-Day Delivery กรุงเทพฯ–ปริมณฑล — นำโครงการส่งภายในวันตั้งแต่ออกแบบบริการและโครงสร้างราคา จนเปิดให้บริการจริง
  • Air-to-Door — ขนส่งพัสดุทางอากาศช่วง Middle-Mile / Line-Haul เส้นทางกรุงเทพฯ–เชียงใหม่ และกรุงเทพฯ–ขอนแก่น ร่วมกับสายการบิน (Air Asia) ต่อเข้าเครือข่ายภาคพื้นจนถึงหน้าบ้าน
  • แอปพลิเคชัน "พร้อมส่ง" — หนึ่งในทีมพัฒนาแบบ startup ตั้งแต่เก็บ requirement ออกแบบการใช้งาน จนขึ้นใช้งานจริง
  • Data Centre และ AI Agent ระดับองค์กร — หนึ่งในทีมวางโครงสร้าง Data Centre รองรับการเชื่อม AI subagent ของแต่ละแผนก พร้อมวางแผนระบบ AI Agent Team ที่รันได้ทั้งระดับแผนกและระดับองค์กร
  • Agentic Coding — เขียนเครื่องมือขายและเครื่องมือการตลาดให้ทีมใช้เองบน Claude Code และ Cowork ครอบคลุมงานตั้งราคา ข้อเสนอ onboarding และรายงานผู้บริหาร
  • วาง Sales OS และกรอบ KPI ที่เป็นระบบเป็นครั้งแรกของฝ่าย

จุดแข็งเชิงบุคคล

ผู้นำทีม — บริหารทีมพัฒนาและทีมการตลาดควบคู่กัน ด้วย Agentic Coding และ BMad

การลงมือทำ — ลงมือเร็วด้วยเครื่องมือ AI ตัดสินใจบนข้อมูล เชื่อมรายละเอียดเข้ากับภาพกลยุทธ์

  • Perplexity & ChatGPT Search — กลยุทธ์การถูกค้นพบบนฐาน LLM
